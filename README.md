# 🧬 생명 기술 질문 챗봇

중학교 3학년 기술 수업 **6단원 '생명 기술의 이해'** 를 공부할 때 쓰는 질문 챗봇이에요.
궁금한 것을 물어보면 AI가 교과서 수준에 맞춰 쉽게 설명해 줘요.

## 🙋 어떻게 쓰나요?

1. 👉 **[챗봇 열기 (여기를 누르세요)](https://anycall2393.github.io/lifetech/)**
2. 학번과 이름을 적어요. (예: 3105 홍길동)
3. 위에서 주제를 골라요: 🧬 전체 · 🐑 핵 이식 · 🧪 유전자 재조합 · 🥔 세포 융합 · 🌱 조직 배양 · ✏️ 직접 입력
4. 예시 질문을 누르거나, 궁금한 것을 직접 적고 **보내기**를 눌러요.

### 💡 이렇게 물으면 자료도 같이 나와요

| 이렇게 물으면 | 나오는 것 |
| :-- | :-- |
| "복제 양 돌리 **영상** 찾아 줘" | ▶️ 유튜브 영상 (채팅에서 바로 재생) |
| "조직 배양 **사진** 보여 줘" | 📷 사진 |
| "GMO **최신 뉴스** 찾아 줘" | 📚 위키백과·뉴스 링크 |

답변 아래 🔎 버튼으로 네이버·다음·구글·유튜브에서 더 찾아볼 수도 있어요.

### ⚠️ 약속

- 이름 외의 개인 정보(전화번호, 주소 등)는 적지 마세요.
- 질문과 답변은 수업 기록으로 선생님 시트에 저장돼요.
- AI의 답이 항상 정확한 것은 아니에요. 중요한 내용은 교과서와 선생님께 확인해요.

## 🔧 이 저장소에 있는 파일 (선생님·만드는 사람용)

| 파일 | 하는 일 |
| :-- | :-- |
| `index.html` | 학생이 보는 화면이에요. GitHub Pages로 공개돼요. 영상·사진·위키백과 검색은 이 화면이 직접 해서 빨라요. |
| `Code.gs` | Google Apps Script에 붙여넣는 서버 코드예요. AI(Gemini) 답변과 구글 시트 기록을 맡아요. **API 키는 GitHub에 올리지 않고 Apps Script에만 넣어요.** |

- 화면과 서버가 짝이 맞는지는 챗봇 제목 옆 버전 글자(예: `· v13`)로 확인해요.
- `Code.gs`를 고친 뒤에는 Apps Script에서 **배포 → 배포 관리 → 연필(수정) → 버전: 새 버전 → 배포**를 해야 반영돼요.
- 입력창에 `/점검`을 보내면 서버 연결과 속도를 한 번에 확인할 수 있어요.
